# 🌍 Концепт: Переход от «Калькулятора проекций» к «Виртуальной лаборатории картографии»

## 🎯 1. Суть проблемы: Геодезические vs Визуальные параметры

В текущей реализации используются **математические параметры** (центральный меридиан $\lambda_0$, стандартные параллели $\phi_1, \phi_2$), которые имеют точный геодезический смысл, но совершенно неинтуитивны для обывателя. Пользователь видит абстрактные градусы (-180…180°) и не понимает физического смысла искажений.

**Решение:** Переход к **визуальным (физическим) параметрам**. Вместо ввода сухих цифр пользователь физически манипулирует геометрическими объектами (цилиндрами, конусами, плоскостями и светом) в 3D-сцене, делая сложную математику осязаемой.

---

## 🔄 2. Механика вспомогательных поверхностей (Как это работает)

Вместо градусов мы даем пользователю физически взаимодействовать со вспомогательными поверхностями на глобусе. При изменении формы или положения объекта 2D-карта пересчитывается в реальном времени.

### 🛢️ Цилиндрические проекции

Пользователь взаимодействует с 3D-цилиндром, надетым на Землю:

* **Диаметр цилиндра (растяжение):** Меняет *масштаб* проекции. Чем больше цилиндр, тем крупнее карта и сильнее искажения.
* **Смещение по оси Y (вверх/вниз):** Определяет *стандартные параллели*. Если цилиндр просто касается экватора — получаем одну линию нулевых искажений. Если он «прорезает» глобус (секущий цилиндр) — получаем две параллели искажений.
* **Поворот вокруг Земли (оси X/Z):** Вращение цилиндра задает *Центральный меридиан*.
* **Угол наклона цилиндра:** Позволяет визуально создавать *косые проекции* (идеально для объяснения навигационных карт, например, для рейса Москва — Нью-Йорк).

### 📐 Конические проекции

Пользователь управляет 3D-конусом:

* **Угол при вершине (раскрытие):** Делаем конус плоским (как зонтик) для полярных широт, или острым (как колпак) для экваториальных. Это определяет *базовую стандартную параллель*.
* **Положение вершины (высота над глобусом):** Задает *вторую стандартную параллель* (превращая касательный конус в секущий).
* **Вращение конуса:** Определяет *Центральный меридиан*.

### 📄 Азимутальные (Плоские) проекции

Пользователь прикладывает плоский диск (лист бумаги) к глобусу:

* **Точка касания (перетаскивание по глобусу):** Прямо задает *широту и долготу центра проекции* (полюс, экватор или любая произвольная точка).
* **Расстояние от плоскости до Земли:** Влияет на масштаб и охват видимой территории.
* **Вращение плоскости:** Задает *ориентацию* (поворот) итоговой карты.

## 💡 3. Киллер-фича: Интерактивный источник света

Ключевой фактор, определяющий тип искажений (равноугольная, равновеликая и т.д.) — это то, как проекционные лучи падают на поверхность. Пользователь получает возможность управлять «лампочкой» в 3D-пространстве.

**Режимы освещения:**

1. **Точечный источник (для азимутальных и перспективных проекций):**
* *В центре Земли* → **Гномоническая проекция** (лучи идут из ядра, все кратчайшие пути становятся прямыми линиями).
* *На противоположной поверхности шара* → **Стереографическая проекция** (сохраняет правильные углы и формы).
* *Бесконечность (параллельные лучи)* → **Ортографическая проекция** (как Земля выглядит из космоса).


2. **Линейный источник (для геометрических цилиндрических проекций):**
Математически цилиндрическая проекция проецируется не из точки, а от оси. В интерфейсе это выглядит как светящийся стержень внутри Земли.
* *Стержень вдоль оси Север-Юг* → Стандартная цилиндрическая.
* *Стержень повернут на 90° (через экватор)* → Трансверсальная цилиндрическая (поперечная).
* *Стержень наклонен* → Косая цилиндрическая.


3. **Математический режим (без света):**
Для проекций, которые нельзя получить геометрически (например, классический *Меркатор* или *Равнопромежуточная*). Свет отключается, а вместо него рисуются красивые пунктирные линии-векторы, показывающие формульный перенос точек с глобуса на поверхность.

## 🎮 4. Пользовательский интерфейс (UI)

Интерфейс должен состоять из интуитивных ползунков (слайдеров) для управления 3D-сценой, в то время как сложная математика спрятана, но доступна по клику.

**Пример панели управления (для цилиндра):**

```text
┌─────────────────────────────────────────────────────┐
│  🌍 Форма и положение цилиндра                      │
├─────────────────────────────────────────────────────┤
│  Диаметр:        [████████░░] 1.2                   │
│  Высота сдвига:  [████░░░░░░] 0.3 (от экватора)     │
│  Поворот карты:  [██░░░░░░░░] -30° (восток)         │
│  Наклон оси:     [██░░░░░░░░] 0° (прямая)           │
│                                                     │
│  Cвет (cgbcjr):                      │
│  ○ Из центра    │
│  ○ Из бесконечности  │
│  ● Математическая      │
│                                                     │
│  [ ℹ️ Показать точные геодезические параметры ] 
   (радом с кнопкой Тиссо)     │
└─────────────────────────────────────────────────────┘

```

**Информационное окно (Geodetic Summary):**
При клике на «ℹ️» экрана отображаются классические параметры, которые пересчитываются в реальном времени при движении слайдеров. Это делает инструмент пригодным не только для игры, но и для профессионального обучения:

> **Точные параметры проекции:**
> * Центральный меридиан ($\lambda_0$): -30°
> * Стандартная параллель 1 ($\phi_1$): 15° С.Ш.
> * Стандартная параллель 2 ($\phi_2$): 15° Ю.Ш.
> * Масштабный коэффициент: 1.2
> * Класс проекции: Секущая равноугольная цилиндрическая
