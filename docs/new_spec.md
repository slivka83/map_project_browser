# 🎛️ ЧАСТЬ 2. Детальный каталог контролов для каждой проекции

Теперь подробно разберём каждый редактируемый контрол.

## 🟫 ГРУППА 1. Цилиндрические проекции (детали)

### 1. Plate Carrée / Equirectangular / Miller / CEA / Behrmann / Gall-Peters

**Контрол #1: «Главная линия» (Standard Parallel 1)**
| Аспект | Деталь |
|---|---|
| **Виджет UI** | Горизонтальный слайдер с ползунком + числовое поле рядом |
| **Диапазон** | от -90° до +90° (с отрицательным направлением) |
| **Шаг** | 0.1° при плавной прокрутке, снэп к 5° при удержании Shift |
| **Пресеты** | Кнопки: «Экватор (0°)», «Москва (55°)», «Тропик (23.5°)» |
| **3D сцена** | Вокруг глобуса вращается полупрозрачный стеклянный цилиндр. При сдвиге ползунка цилиндр **сжимается или расширяется**, меняя радиус. Когда радиус равен радиусу глобуса на выбранной широте — цилиндр «касается» глобуса, и в этом месте появляется **зелёное светящееся кольцо**. Если слайдер на 0° — кольцо на экваторе. Если 45° — два кольца (северное и южное). |
| **2D карта** | Линия, соответствующая параллели слайдера, становится **линией идеального масштаба**. Все, что ближе к экватору — немного растянуто, все, что дальше — сжато. При сдвиге слайдера вся сетка меридианов/параллелей «скользит» по прямоугольнику. |

**Контрол #2: «Повернуть карту» (Central Meridian)**
| Аспект | Деталь |
|---|---|
| **Виджет UI** | Круговой слайдер (как циферблат часов) или горизонтальный с диапазоном |
| **Диапазон** | от -180° до +180° (или 0–360°) |
| **Шаг** | 1° |
| **Пресеты** | Кнопки: «Гринвич (0°)», «Урал (60°)», «Камчатка (160°)», «Тихий океан (-150°)» |
| **3D сцена** | На глобусе появляется **красная вертикальная линия** — будущий разрез цилиндра. При движении ползунка эта линия вращается вокруг глобуса, как нитка на клубке. Вся остальная сетка меридианов вращается вместе с ней относительно цилиндра (или наоборот — цилиндр вращается). |
| **2D карта** | Карта «перематывается» влево-вправо. Меридиан, выбранный ползунком, становится **центральной вертикальной линией** на 2D карте. Крайние меридианы (±180°) — по бокам прямоугольника. |

**Контрол #3: «Масштаб экватора» (только для Equirectangular)**
| Аспект | Деталь |
|---|---|
| **Виджет UI** | Слайдер с коэффициентом |
| **Диапазон** | от 0.5 до 2.0 |
| **Шаг** | 0.05 |
| **Пресет** | «1.0 — идеально», «2.0 — удвоить ширину» |
| **3D сцена** | Цилиндр **растягивается или сжимается** вдоль оси, меняя высоту. |
| **2D карта** | Прямоугольник становится шире или уже, меняя соотношение сторон. При k=2.0 карта становится «квадратной» — популярный вид для художественных визуализаций. |

### 3. Mercator (обычный)

**Контрол #1: «Как растягивать полюса?» (Standard Parallel или Scale Factor)**
| Аспект | Деталь |
|---|---|
| **Виджет UI** | **Радио-переключатель** с двумя режимами: «Тянуть за линии» (слайдер параллели) / «Коэффициент растяжения» (поле ввода k₀) |
| **Диапазон (режим 1)** | от -90° до +90° (слайдер) |
| **Диапазон (режим 2)** | от 0.5 до 2.0 (числовое поле) |
| **Автоматика** | При изменении одного значения второе пересчитывается автоматически в реальном времени |
| **3D сцена** | Полупрозрачный цилиндр сжимается/расширяется. При k₀=1 цилиндр касается экватора. При k₀<1 цилиндр **прорезает** глобус на двух широтах (секущий цилиндр). На 3D появляются **две светящиеся окружности** — линии нулевых искажений. |
| **2D карта** | В режиме секущего цилиндра: на 2D карте появляются две горизонтальные линии, где масштаб идеален. Между ними — легкое сжатие, снаружи — растяжение. Это полезно для карт стран, вытянутых вдоль этих линий. |

**Контрол #2: «Где сделать разрез?» (Central Meridian)**
| Аспект | Аналогично Plate Carrée (см. выше) |
|---|---|

**Контрол #3: «Обрезать карту» (Latitude of Origin / Bounds)**
| Аспект | Деталь |
|---|---|
| **Виджет UI** | Два ползунка (верх и низ) на боковой линейке карты |
| **Диапазон** | от -85.06° до +85.06° (дальше Меркатор математически уходит в бесконечность) |
| **3D сцена** | На 3D глобусе появляются две горизонтальные «гильотины», которые обрезают цилиндр сверху и снизу. |
| **2D карта** | Карта «обрезается» в этих широтах. Полюсов не видно — они за кадром. Так работают Яндекс.Карты и Google Maps (±85.06°). |

### 4. Transverse Mercator (Поперечный Меркатор / UTM)

**Контрол #1: «Номер зоны UTM»**
| Аспект | Деталь |
|---|---|
| **Виджет UI** | Выпадающий список (1–60) + поле «Авто» |
| **Диапазон** | 1 до 60 |
| **Поведение** | При выборе зоны автоматически подставляется Центральный меридиан (зона N → λ = (N-1)*6° - 180° + 3°) |
| **3D сцена** | Цилиндр **поворачивается на бок** (становится «горизонтальным»), касаясь выбранного меридиана. Вокруг этого меридиана появляется **узкая светящаяся полоса** шириной 6° — это зона UTM. |
| **2D карта** | На 2D карте показывается **только одна зона** (узкий вертикальный прямоугольник шириной ~666 км). Меридиан зоны — центральная вертикальная линия, искажения минимальны. |

**Контрол #2: «Коэффициент масштаба» (k₀)**
| Аспект | Деталь |
|---|---|
| **Виджет UI** | Числовое поле с инкрементом 0.0001 |
| **Диапазон** | от 0.9990 до 1.0010 |
| **Пресет** | «0.9996 (стандарт UTM)», «1.0 (касательный)», «0.9999 (Gauss-Krüger)» |
| **3D сцена** | При k₀ < 1 цилиндр чуть меньше глобуса и **прорезает** его по двум меридианам. На 3D появляются две вертикальные светящиеся линии. |
| **2D карта** | Вдоль центрального меридиана — легкое сжатие (на 0.04% для UTM). На краях зоны — растяжение. Две линии секущего цилиндра — линии идеального масштаба. |

**Контрол #3: «Сместить нуль координат» (False Easting / Northing)**
| Аспект | Деталь |
|---|---|
| **Виджет UI** | Два числовых поля (X и Y) |
| **Диапазон** | от -10,000,000 до +10,000,000 метров |

# 🎯 ЧАСТЬ 5. Приоритет UX: какие контролы показывать первым

Чтобы не перегрузить обывателя, применим принцип **«прогрессивного раскрытия»**:

## Уровень 1: Сразу видны (0 кликов)

Для любой проекции показываем **только самое важное**:

1. **«Повернуть карту»** (Central Meridian) — есть у 95% проекций
2. **«Где центр?»** (φ₀, λ₀) — есть у 70% проекций
3. **«Главные линии»** (Standard Parallels) — для цилиндров и конусов
4. **Кнопка «📦 Развернуть»** — всегда на виду
5. **Кнопка «🔴 Показать искажения»** — всегда активна

## Уровень 2: По кнопке «⚙️ Больше настроек»

- Масштабные коэффициенты (k₀)
- False Easting/Northing (скрыть под «Технические параметры»)
- Азимут оси (для косых проекций)
- Параметры орбиты (для SOM)

## Уровень 3: В «Настройки эксперта»

- Выбор эллипсоида (WGS84 vs GRS80 vs сфера)
- Переключение датума (NAD27 ↔ NAD83 ↔ WGS84)
- Ручной ввод PROJ-строки
- Экспорт/импорт WKT

# 📝 Заключение: философия интерфейса

Главная идея приложения — **«покажи мне, как это работает»**.

- Обывателю не нужно знать, что такое «False Easting = 500,000 м в UTM». Ему нужно **увидеть**, что на 3D глобусе цилиндр касается меридиана, а на 2D карте этот меридиан становится «осью X=500,000», чтобы все координаты были положительными.
- Он не должен понимать формулу Меркатора. Он должен **увидеть**, как при сдвиге слайдера параллели цилиндр «сжимается», а на 2D карте появляются две горизонтальные линии нулевых искажений.
- Он не должен знать про Tissot Indicatrix. Он должен **увидеть**, как одинаковые кружочки на глобусе превращаются в сплющенные овалы на карте.

**Визуальное взаимодействие должно быть таким:**
```
Пользователь крутит слайдер → 3D объект двигается (физически!) → 2D карта мгновенно перерисовывается → Пользователь понимает причину и следствие
```

Это превращает картографию из скучной науки в интерактивную песочницу, где любой может открыть для себя, почему карта мира в его телефоне выглядит именно так.
