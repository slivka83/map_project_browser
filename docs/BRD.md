# Бизнес-требования (BRD): Интерактивный симулятор картографических проекций «Carto-Space»

## 1. Обзор проекта

* Создать веб-инструмент для наглядной демонстрации картографических проекций — связи трёхмерной модели Земли и её плоского картографического представления.
* Продукт позиционируется как учебный симулятор принципов картографии.

## 2. Целевая аудитория

* Студенты и преподаватели картографии, геодезии и смежных дисциплин.
* ГИС-аналитики, подбирающие проекцию под задачу.
* Разработчики геоинформационных систем.

## 3. Эстетика и концепция интерфейса

* Тёмная тема, высокий контраст, минимализм, неоновые акценты.
* Стиль «панели управления космического корабля»: профессиональный, строгий, технологичный инструмент.

## 4. Архитектура рабочего пространства

Рабочая область разделена на две зоны:

1. **Левая панель (примерно треть ширины):**
   * Верхний блок — панель управления параметрами проекции.
   * Нижний блок — трёхмерная сцена (глобус, вспомогательная поверхность, лучи проецирования).

2. **Правая панель (примерно две трети ширины):**
   * Двумерная карта, синхронизированная с трёхмерной сценой.

## 5. Функциональные требования

### 5.1. Управление параметрами проекции

* Все настройки доступны в едином плоском списке без вложенных меню и скрытых уровней.

**Общие настройки:**
* **Семейство проекции:** выбор цилиндрической, конической или азимутальной поверхности.
* **Тип искажения:** выбор сохраняемого свойства — форма, площадь или расстояния.
* **Библиотека готовых проекций (EPSG):** кнопка вызова каталога систем координат.

**Источник света (только для азимутальной проекции):**
* Доступен выбор одного из режимов: из центра Земли, из противоположной точки, из бесконечности (параллельные лучи), автоматический.
* Для конформной азимутальной проекции переключатель источника света отображается, но заблокирован для выбора.
* Для остальных типов искажений переключатель активен.

**Геодезические параметры:**
* **Центр проекции:** центральные широта и долгота.
* **Масштабный коэффициент:** степень погружения вспомогательной фигуры в глобус для цилиндра; степень приближения для конуса и азимутальной.
* **Ложное смещение:** учитывается в точных параметрах, но не выносится в интерфейс слайдерами.
* **Угол наклона:** поворот вспомогательной поверхности относительно глобуса.

**Модель Земли:**
* Только сферическая модель. Переключатель «сфера/эллипсоид» не предусмотрен.

### 5.2. Каталог готовых проекций (EPSG)

* По нажатию открывается модальное окно с таблицей систем координат: код, название, тип, единицы измерения.
* Доступны поиск и фильтрация по любому полю.
* При выборе строки окно закрывается, а параметры проекции на панели и обеих визуализациях перестраиваются под выбранную систему.

### 5.3. Визуализация и обратная связь

**Трёхмерная сцена:**
* **Глобус** — тёмная сфера с очертаниями материков и сеткой параллелей и меридианов.
* **Вспомогательная поверхность** — полупрозрачный каркас (цилиндр, конус или плоскость), меняющий положение и форму при изменении параметров.
* **Лучи проецирования** — постоянно видимая расчёска сплошных линий, соединяющая точки глобуса с вспомогательной поверхностью.
* **Маркер источника света** — светящийся маркер у точки источника (для азимутальной и конической проекций), без текстовых подписей.

**Двумерная карта:**
* Отрисовка в реальном времени со всеми выбранными параметрами.
* Возможность наложения индикатрис Тиссо.

## 6. Логика взаимодействия

* Любое действие пользователя мгновенно отражается на трёхмерной сцене, лучах и двумерной карте одновременно.
* При загрузке проекции из каталога параметры на панели управления принимают её значения.

## 7. Критерии приёмки

1. Пользователь без специального образования понимает связь между вспомогательной фигурой в трёхмерной сцене и видом плоской карты.
2. Все функции управления доступны сразу, без дополнительных меню и вкладок.
3. Изменение любого параметра не вызывает видимых задержек.
4. Модель проекций корректна для сферической Земли.
5. Визуальный стиль выдержан во всех элементах.
