# Бизнес-требования (BRD): Интерактивный симулятор картографических проекций «Carto-Space»

## 1. Обзор проекта

* Создать веб-инструмент для наглядной демонстрации картографических проекций — связи трёхмерной модели Земли и её плоского картографического представления.
* Продукт позиционируется как учебный симулятор принципов картографии: как точки глобуса переносятся на разворачиваемую поверхность (цилиндр, конус, плоскость) и что при этом происходит с картой.
* Продукт должен оставаться простым: немного проекций, немного параметров, только действительно наглядные способы визуализации. Инженерно-геодезические темы (UTM-зоны, орбитальные проекции, спутниковые снимки, каталоги EPSG) в продукт не входят.

## 2. Целевая аудитория

* Студенты и преподаватели картографии, геодезии и смежных дисциплин.
* Все, кто хочет понять, как трёхмерная Земля превращается в плоскую карту.

## 3. Эстетика и концепция интерфейса

* Тёмная тема, высокий контраст, минимализм, неоновые акценты.
* Стиль «панели управления космического корабля»: профессиональный, строгий, технологичный инструмент.

## 4. Архитектура рабочего пространства

Рабочая область разделена на две зоны:

1. **Левая панель (примерно треть ширины):**
   * Верхний блок — выбор проекции и сброс параметров.
   * Средний блок — панель параметров проекции и визуализации.
   * Нижний блок — трёхмерная сцена (глобус, вспомогательная поверхность, лучи проецирования).

2. **Правая панель (примерно две трети ширины):**
   * Двумерная карта, синхронизированная с трёхмерной сценой.

## 5. Функциональные требования

### 5.1. Управление параметрами проекции

* Все настройки доступны в едином плоском списке без вложенных меню и скрытых уровней.

**Общие настройки:**
* **Семейство проекции:** выбор одного из трёх семейств — цилиндрическое (цилиндр), коническое (конус), азимутальное (касательная плоскость).
* **Выбор проекции:** ниспадающий список из 7 именованных проекций, сгруппированных по трём семействам:
  * цилиндрические — равнопромежуточная (плоская развёртка), Меркатор;
  * конические — конформная Ламберта, равновеликая Альберса;
  * азимутальные — гномоническая, стереографическая, ортографическая.
* **Тип искажения** задаётся неявно выбранной проекцией (каждая проекция фиксирует своё сохраняемое свойство — форма, площадь или расстояния).

**Источник света (азимутальные проекции):**
* Положение источника фиксировано проекцией: из центра Земли (гномоническая), из противоположной точки (стереографическая), из бесконечности — параллельные лучи (ортографическая).
* Для цилиндрических проекций лучи идут из центра глобуса на цилиндр; для конических — из вершины конуса.

**Геодезические параметры:**
* **Долгота центра (λ₀)** — у всех проекций.
* **Широта центра / параллель 1 (φ₀/φ₁)** — у всех проекций (для азимутальных это точка касания плоскости).
* **Параллель 2 (φ₂)** — для секущих конусов (касательный/секущий переключатель).
* **Масштабный коэффициент:** степень погружения цилиндра в глобус для цилиндрических; степень приближения для конуса и плоскости.
* **Наклон (γ)** — поворот карты вокруг точки касания, только для азимутальных проекций.
* **Полушарие (север/юг)** — для конических проекций.
* **Ложное смещение:** учитывается в точных параметрах, но не выносится в интерфейс слайдерами.

**Контекстно-зависимые элементы управления** (показываются только для соответствующих проекций):
* **Пресеты точки касания** — для азимутальных проекций.

**Модель Земли:**
* Только сферическая модель. Переключатель «сфера/эллипсоид» не предусмотрен.

### 5.2. Визуализация и обратная связь

**Трёхмерная сцена:**
* **Глобус** — тёмная сфера с очертаниями материков (без координатной сетки: сетка показывается только на 2D-карте).
* **Вспомогательная поверхность** — полупрозрачный каркас (цилиндр, конус или плоскость), меняющий положение и форму при изменении параметров.
* **Лучи проецирования** — постоянно видимая расчёска сплошных линий, соединяющая точки глобуса с вспомогательной поверхностью (из центра глобуса — цилиндрические, из вершины конуса — конические, из положения источника — азимутальные). Лучи показываются всегда, без переключателя.
* **Маркер источника света** — светящийся маркер у точки источника (для азимутальных и конических проекций), без текстовых подписей.
* **Кольца пересечения** — зелёные кольца в местах касания вспомогательной поверхности и глобуса.

**Двумерная карта:**
* Отрисовка в реальном времени со всеми выбранными параметрами.
* Возможность наложения индикатрис Тиссо, слоя границ стран, координатной сетки (кнопка «Сетка» в углу карты) и переключения детализации карты.
* Показатель искажения площади в углу карты.
* Связка наведения: наведение курсора на карту или глобус подсвечивает ту же точку на другой вьюхе и (при включении) показывает луч проекции точки.
* Показываются линия разреза (развёртки) поверхности и маркер точки касания.

## 6. Логика взаимодействия

* Любое действие пользователя мгновенно отражается на трёхмерной сцене, лучах и двумерной карте одновременно.
* При выборе проекции из списка параметры на панели управления принимают её значения.

## 7. Критерии приёмки

1. Пользователь без специального образования понимает связь между вспомогательной фигурой в трёхмерной сцене и видом плоской карты.
2. Все функции управления доступны сразу, без дополнительных меню и вкладок.
3. Изменение любого параметра не вызывает видимых задержек.
4. Модель проекций корректна для сферической Земли.
5. Визуальный стиль выдержан во всех элементах.
6. Количество проекций, параметров и способов визуализации остаётся минимально достаточным для обучения: 7 проекций в 3 семействах.
