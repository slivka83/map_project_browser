# Бизнес-постановка задачи: «Carto-Space» (реверс-инжиниринг)

> Документ восстановлен **только по фактическому поведению готового продукта**, как если бы исходного кода ещё не существовало. Описывает, *что* система делает для пользователя, а не *как* она реализована.

---

## 1. Назначение и цель продукта

**Carto-Space** — интерактивный обучающий симулятор картографических проекций. Цель продукта — наглядно показать пользователю связь между трёхмерной Землёй и её плоским (двумерным) картографическим изображением, продемонстрировать, как и где при проецировании возникают искажения площадей, углов и расстояний.

Система позволяет пользователю «поиграть» с параметрами проекции и в реальном времени увидеть результат одновременно в двух представлениях: на трёхмерном глобусе (с вспомогательной развёртываемой поверхностью) и на плоской карте.

## 2. Целевая аудитория

- Студенты и преподаватели геодезии, картографии, географии.
- Все, кто хочет интуитивно понять устройство картографических проекций без математики.

Интерфейс должен быть **понятным без специальной подготовки**: все элементы управления видимы одновременно, скрытых уровней настроек нет.

## 3. Функциональные требования

### 3.1. Экранные области (макет)

Приложение занимает весь экран и делится на две части:

- **Левая панель (≈1/3 ширины)** сверху вниз:
  1. Панель параметров (управление проекцией).
  2. Трёхмерная сцена глобуса.
- **Правая панель (≈2/3 ширины)**: плоская двумерная карта, синхронизированная с глобусом в реальном времени.

### 3.2. Панель параметров (управление)

Панель содержит **все** элементы управления, видимые одновременно (без вложенных меню и скрытых уровней):

1. **Выбор семейства проекции** — три кнопки с пиктограммами (иконками), переключающие класс поверхности:
   - Цилиндрическая.
   - Коническая.
   - Азимутальная.
2. **Выбор характера искажений** — выпадающий список:
   - Равноугольная (сохраняет углы).
   - Равновеликая (сохраняет площади).
   - Равнопромежуточная (сохраняет расстояния).
3. **Слайдеры геодезических параметров**:
   - Центральный меридиан (`λ₀`): −180°…+180°.
   - Широта начала отсчёта (`φ₀`): −90°…+90°.
   - Масштабный коэффициент (погружение вспомогательной поверхности): 0.9…1.1.
4. **Кнопка-иконка «Индикатрисы Тиссо»** — переключает отображение сетки искажений на карте.
5. **Кнопка-иконка «Библиотека EPSG»** — открывает каталог готовых проекций (см. §3.5).

### 3.3. Трёхмерная сцена (глобус)

В левой нижней части отображается интерактивная трёхмерная сцена:

- **Полупрозрачная тёмная сфера** (условная Земля).
- **Береговые линии и гратула** — неоново-голубые трёхмерные линии поверх сферы.
- **Вспомогательная развёртываемая поверхность** (та, на которую «проецируется» Земля), полупрозрачная неоново-оранжевая, выбирается по семейству:
  - Цилиндрическая → **цилиндр** вокруг сферы.
  - Коническая → **конус**, касательный к сфере на широте `φ₀`.
  - Азимутальная → **плоскость**, касательная к сфере в точке `(λ₀, φ₀)`.
  - Масштабный коэффициент управляет тем, насколько поверхность «погружается» в сферу.
- **Кольца касания** (неоново-оранжевые) — подчёркивают стандартную параллель/точку касания на вспомогательной поверхности.
- **Веер лучей проекции** для центрального меридиана: линии от поверхности сферы к соответствующим точкам вспомогательной поверхности (наглядно показывают, как точки Земли «переносятся» на плоскость).
- Камера фиксирована под небольшим углом сверху, с перспективой.

### 3.4. Двумерная карта

В правой части отображается плоская карта (SVG):

- **Береговые линии** мира (тёмный фон, неоново-голубые контуры).
- **Гратула** (сетка меридианов/параллелей) — приглушённым цветом.
- **Индикатрисы Тиссо** (переключаются кнопкой из §3.2.4): сетка малых окружностей (~5°), показывающая искажения проекции — их форма и размер наглядно демонстрируют, где и как именно искажается карта.
- Карта всегда синхронизирована с текущими параметрами проекции и глобусом.

### 3.5. Библиотека EPSG (каталог готовых проекций)

Модальное окно (поверх всего интерфейса), открываемое кнопкой «Библиотека EPSG»:

- **Поиск/фильтр** — единое текстовое поле, фильтрующее записи по любому из полей: код, название, тип, единицы, вид проекции (семейство).
- **Таблица** со столбцами:
  1. **Код (EPSG)** — например, `EPSG:4326`.
  2. **Вид проекции** — семейство (Цилиндрическая / Коническая / Азимутальная).
  3. **Название** — имя проекции.
  4. **Тип** — разновидность (Меркатор, Альберс, Стереографическая и т.п.).
  5. **Единицы измерения** — метры / градусы.
- **Выбор строки** применяет соответствующий набор параметров проекции (семейство, искажения, широта начала отсчёта и пр.) ко всему приложению и закрывает окно — так пользователь видит «под капотом», из каких параметров собрана та или иная реальная проекция.
- Каталог содержит порядка ~30 распространённых нормальных проекций.

### 3.6. Параметры состояния (модель данных)

Состояние приложения плоское и содержит:

| Параметр | Диапазон / значения | Назначение |
|---|---|---|
| `family` | cylindrical / conic / azimuthal | Семейство (класс) проекции |
| `distortion` | conformal / equalArea / equidistant | Характер сохраняемого свойства |
| `lambda0` | −180…180 | Центральный меридиан |
| `phiOrigin` | −90…90 | Широта начала отсчёта (стандартная параллель) |
| `scaleFactor` | 0.9…1.1 | Коэффициент погружения вспомогательной поверхности |
| `falseEasting` | −1000…1000 | Условное смещение по оси X |
| `falseNorthing` | −1000…1000 | Условное смещение по оси Y |
| `showTissot` | boolean | Показывать ли индикатрисы Тиссо |

Пользователь может менять любой параметр по отдельности; применение пресета из библиотеки EPSG перезаписывает сразу несколько полей.

## 4. Математика проекций (наблюдаемое поведение)

Система поддерживает фиксированную матрицу **9 комбинаций** «семейство × искажение»:

| Семейство \ Искажение | Равноугольная | Равновеликая | Равнопромежуточная |
|---|---|---|---|
| Цилиндрическая | Меркатор | Цилиндрическая равновеликая (параллель = `φ₀`) | Равнопромежуточная цилиндрическая (платте-карре) |
| Коническая | Коническая равноугольная (Ламберт) | Коническая равновеликая (Альберс) | Коническая равнопромежуточная |
| Азимутальная | Стереографическая | Азимутальная равновеликая (Ламберт) | Азимутальная равнопромежуточная |

К выбранной проекции применяются глобальные параметры разворота/масштаба/сдвига:

- Поворот вокруг Земли задаётся центральным меридианом и широтой: `rotate([−λ₀, −φ₀])`.
- Масштаб: `scale(100 × scaleFactor)`.
- Сдвиг начала координат: `translate([400 + falseEasting, 300 + falseNorthing])`.

Для конических проекций используется **один касательный параллель** на широте `φ₀` (конус центрируется на стандартной параллели). Для цилиндрической равновеликой стандартная параллель также задаётся `φ₀`.

## 5. Нефункциональные требования

1. **Архитектура**: клиентское SPA, **без бэкенда и без внешних API**. Вся математика проекций и геометрия считаются в браузере. Береговые данные поставляются вместе с приложением (локальный файл геоданных).
2. **Язык интерфейса**: русский (все подписи, названия, каталоги).
3. **Производительность**: пересчёт проекции, путей и геометрии лучей должен происходить «на лету» при изменении параметров, без заметных задержек (мемоизация, без пересчёта на каждом кадре анимации).
4. **Доступность**: используются доступные стандартные элементы управления (слайдеры, выпадающие списки) с подписями/подсказками.
5. **Визуальный стиль**: тёмная «космическая панель управления», высококонтрастные неоновые акценты. Неоново-голубой — для глобуса, берегов, активных элементов; неоново-оранжевый — для вспомогательной поверхности, лучей проекции, колец касания. Панели — полупрозрачные («стеклянные») с размытием фона.
6. **Данные о берегах**: загружаются при старте приложения из локального источника (векторные контуры суши мира).

## 6. Ограничения и допущения (в рамках MVP)

- Двумерные проекции строятся для **шаре** (сфера), а не для эллипсоида; модель Земли — сферическая.
- Каталог EPSG содержит только «нормальные» (не повёрнутые/не сдвинутые) проекции с одним стандартным параллелем для конусов.
- Трёхмерная сцена — иллюстративная (наглядная), а не инженерно-точная модель развёртки.
- Все элементы управления видимы постоянно; отсутствуют скрытые/вложенные уровни настроек.

## 7. Критерии приёмки (наблюдаемые)

- При смене семейства/искажения карта и глобус мгновенно пересчитываются.
- Слайдеры `λ₀`, `φ₀`, `scaleFactor` реально влияют на положение, форму и масштаб отображения.
- Кнопка Тиссо включает/выключает сетку индикатрис на карте.
- Поиск в каталоге EPSG фильтрует по любому полю; выбор строки применяет параметры и отражается на всех слайдерах и обеих визуализациях.
- Интерфейс стабилен, тёмный, с неоновыми акцентами, на русском языке, без обращений к серверу.
